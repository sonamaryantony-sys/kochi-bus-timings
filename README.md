# Kochi Bus Timings

Live Website: https://sonamaryantony-sys.github.io/kochi-bus-timings/

A simple website to find KSRTC and Private bus timings in Kochi.

Features:
- Search buses from Ernakulam, Kakkanad, Aluva, Fort Kochi
- Shows time, type, fare
- Works on mobile

Made with HTML, CSS, JavaScript
Hosted on GitHub Pages
